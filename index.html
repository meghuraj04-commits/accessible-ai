Auditing Framework

WCAG 6-Point Compliance Standards

Clear, testable standards for visual, textual, keyboard, and screen reader accessibility for people with disabilities.

W3C Level AA Standards
🎨 1. Color Contrast SC 1.4.3, 1.4.11, 1.4.1
  • Normal Text: Requires minimum contrast ratio of 4.5:1 against background (Level AA).
  • Large Text: Requires minimum contrast ratio of 3:1 (18pt/24px or 14pt/18.6px bold+).
  • UI Components & Graphics: Non-text inputs, buttons, and icons need 3:1 contrast against adjacent colors.
  • Color Alone (SC 1.4.1): Color cannot be sole indicator; add text labels, icons, or patterns.
✓ Active in Audit Engine
🖼️ 2. Alt Text for Images SC 1.1.1 Non-text Content
  • Informational Images: Must have text alternative (alt attribute) conveying equivalent meaning.
  • Decorative Images: Hidden from screen readers using empty alt="" or presentation role.
  • Functional Images: Buttons/icons describe action or destination, not just picture.
✓ Active in Audit Engine
🔤 3. Fonts & Text Spacing SC 1.4.12 Text Spacing
  • Font Size: Industry consensus recommends minimum 16px for comfortable body text.
  • User-Customized Spacing: Content must not break or clip when custom styles are applied:
    • Line height ≥ 1.5x  • Paragraph spacing ≥ 2x
    • Letter spacing ≥ 0.12x  • Word spacing ≥ 0.16x
  • Legible Letterforms: Clean typefaces with distinct capital I, lowercase l, and number 1.
✓ Active in Audit Engine
⌨️ 4. Keyboard Operability SC 2.1.1 & 2.4.7 Focus
  • Keyboard Operable: Every interactive element (links, buttons, form fields) operable via keyboard alone.
  • Visible Focus Indicator: Visible focus indicator meeting contrast rules.
  • No Keyboard Trap (SC 2.1.2): Focus can exit components via standard Tab/Escape keys.
✓ Active in Audit Engine
🔍 5. Resize Text SC 1.4.4 (200% Zoom)
  • 200% Zoom: Users can zoom text up to 200% using browser controls.
  • Layout Integrity: No layout breakdown, overlapping boxes, or horizontal scrolling chaos.
  • Meta Viewport: Must not lock zoom using user-scalable=no or maximum-scale=1.
✓ Active in Audit Engine
🌐 6. Page Language SC 3.1.1 Language
  • Declared Language: Primary human language declared in HTML code (e.g., <html lang="en">).
  • Pronunciation: Enables screen readers to pronounce words correctly with accurate phonetics.
  • Multilingual Support: Explicit language tags for international accessibility.
✓ Active in Audit Engine
